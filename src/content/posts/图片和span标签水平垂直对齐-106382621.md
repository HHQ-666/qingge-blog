###### HTML

```
<ul class="topUl">
  <li>
    <img src="@/assets/propertyPayCost.png">
    <span>物业缴费</span>
  </li>
</ul>
```

###### CSS

```
.topUl li {
  height: 60px;
  line-height: 60px;
}
.topUl img {
  width: 24px;
  margin-right: 8px;
  vertical-align: middle;
}
.topUl span {
  vertical-align: middle;
}
```
