### 方法一：for循环遍历每一项相加

```
 function sumArr (arr) {
      var sum = 0;
      for(var i = 0;i<=arr.length;i++){
    	sum += arr[i];
    	// 若果不是数字类型  
    	// sum += +arr[i];
   	 }
  return sum;
}
```

### 方法二：es6的forEach方法

```
function sumArr (arr) {
	var sum = 0;
    arr.forEach(function(val){
    	sum += val;
    })
    return sum;
}
```

### 方法三：eval（）

```
//直接把他变成各个数的加法运算字符串
function sumArr(arr){
	return eval(arr.join("+")) 
}
```

### 方法四：函数式编程写法

```
array.reduce(function(prev, current, currentIndex, arr), initialValue)
```

- prev：函数传进来的初始值或上一次回调的返回值
- current：数组中当前处理的元素值
- currentIndex：当前元素索引
- arr：当前元素所属的数组本身
- initialValue：传给函数的初始值

```
function sumArr(arr){
	return arr.reduce(function(prev,cur){
        return prev + cur;
    },0);
}
```
