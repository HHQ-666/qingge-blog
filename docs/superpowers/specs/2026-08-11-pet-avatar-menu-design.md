# 宠物圆头像选择浮窗设计规格

**日期：** 2026-08-11  
**状态：** 已确认，待实现

## 目标

将宠物选择浮窗收敛为一个轻量的圆头像选择器，避免模型预览图比例不稳定、文字和操作入口堆叠造成的视觉噪音。

## 方案

### 可见宠物

- 只展示 `pio`、`shizuku`、`koharu` 三个形象。
- 从展示清单中移除 `haru`。
- 暂不删除现有模型和头像资源，避免影响缓存、回滚或其他引用。

### 浮窗结构

- 浮窗只保留一排三个圆形头像按钮。
- 移除标题栏、宠物名称、选中勾号和底部动作区域。
- 移除浮窗内的隐藏宠物按钮；点击浮窗外部或按 `Escape` 关闭浮窗。
- 保留头像按钮的无障碍名称和单选语义，视觉上不显示文字。

### 视觉样式

- 使用半透明白色玻璃背景、柔和阴影和圆角胶囊容器，延续页面现有的浅紫氛围。
- 暗色主题使用深色半透明背景，保证头像和选中态有足够对比度。
- 头像采用圆形裁切，尺寸统一，避免不同模型头像比例造成卡片高度变化。
- 当前形象只增加一圈主题色边框，不额外显示勾号或文字。
- 保留轻微 hover/focus 状态，减少移动端触摸时的视觉跳动。

### 交互与兼容

- 点击头像继续切换模型并关闭浮窗。
- 右键宠物仍然打开选择浮窗。
- 不改变模型加载、预加载、静态宠物动作及内部动作映射逻辑。
- 不新增或删除模型文件，只更新展示清单、组件标记和相关测试。

## 验收标准

- 浮窗只出现三个圆形头像，没有标题、名称、勾号或底部按钮。
- 选中头像外有清晰但不突兀的主题色边框。
- 浅色和暗色主题下，浮窗背景、头像和边框都清晰可辨。
- 右键打开、点击切换、点击外部关闭、`Escape` 关闭均正常。
- 宠物清单测试、类型检查和构建通过。
