# 小屋宠物（Pet Companion）设计文档

> 日期：2026-08-06
> 状态：已确认，待实施
> 关联项目：清哥的小屋（Astro 5 个人博客）

## 1. 背景与目标

「清哥的小屋」是以"小屋 + 大海"为主题的个人博客（定位：一个菜鸟的成长之路），已有华语金曲电台、今日一言、Splash 开场、鼠标彩带等趣味功能。本功能为站点新增一只**养成系全站悬浮宠物**，强化小屋世界观与访客粘性。

与用户确认的核心需求：

- **形象自由可换**：作者维护形象库（图片素材目录 + JSON 清单），访客可在面板里"收养"喜欢的形象，选择存浏览器本地
- **多姿势素材**：每个形象配多张姿势图，随时段与互动切换
- **养成系**：亲密度成长 + 等级称号，数据存浏览器本地（"你和你的宠物的私人羁绊"）
- **展示**：全站悬浮，左下角 FAB（避开右下角电台 FAB 与返回顶部按钮）
- **架构**：纯前端（Astro + Svelte + localStorage），零后端改动，Vercel 直接部署

## 2. 架构与文件布局

| 文件 | 职责 |
|------|------|
| `src/components/fun/PetCompanion.svelte` | 宠物主组件：FAB、面板、姿势切换、气泡、粒子、亲密度逻辑 |
| `src/scripts/pet-logic.mjs` | 核心逻辑纯函数模块（亲密度计算、等级判定、姿势时段选择），沿用 `src/scripts/` 惯例 |
| `src/layouts/Layout.astro` | 挂载点，由 `funConfig.pet.enable` 控制 |
| `src/config.ts` | 新增 `funConfig.pet` 开关与参数 |
| `public/pets/manifest.json` | 形象库清单（作者维护） |
| `public/pets/<形象id>/<姿势>.png` | 形象姿势图片 |
| `scripts/test/pet-logic.test.mjs` | 亲密度 / 等级 / 每日上限核心逻辑单元测试 |

**选型理由**：

- 用 Svelte 而非 Astro 内联 script：姿势切换、气泡、面板、粒子等交互状态多，Svelte 响应式更清晰（项目已有 `Search.svelte`、`DisplaySettings.svelte` 先例）
- 形象素材放 `public/`：作者"丢图 + 编辑 JSON"即可新增形象，零代码改动；也可通过 CMS（`/admin/`，Sveltia）管理
- 核心逻辑（亲密度计算、等级判定、姿势时段选择）抽为纯函数模块，便于单元测试

## 3. 数据模型

### 3.1 形象清单 `public/pets/manifest.json`

```json
{
	"pets": [
		{
			"id": "pikachu",
			"name": "皮卡丘",
			"poses": {
				"idle": "pikachu/idle.png",
				"sleep": "pikachu/sleep.png",
				"happy": "pikachu/happy.png"
			},
			"quotes": ["皮卡~丘!", "十万伏特!今天也要元气满满"]
		}
	]
}
```

字段说明：

- `id`：唯一标识，同时作为素材目录名
- `name`：展示名称
- `poses`：最小姿势集为 `idle` / `sleep` / `happy` 三张；缺失的姿势运行时回退到 `idle`；路径相对于 `/pets/`，支持 png / jpg / webp / gif
- `quotes`：自定义语录数组，可选；未配置时说话气泡改用今日一言

### 3.2 本地存储 `localStorage`，key：`qingge-pet-v1`

```json
{
	"adopted": "pikachu",
	"intimacy": 120,
	"lastVisit": "2026-08-06",
	"todayPets": 3,
	"todayStayRewards": 5
}
```

- 等级由 `intimacy` 实时计算派生，不单独存储
- `lastVisit` 与本地日期比较，用于每日上限重置与回访奖励判定
- `localStorage` 不可用时降级为内存模式（刷新重置，不报错）

## 4. 核心机制

### 4.1 姿势时刻表

| 时间 | 姿势 |
|------|------|
| 6:00–23:00 | idle（精神） |
| 23:00–6:00 | sleep（睡觉） |
| 被抚摸时 | 临时切 happy，2–3 秒后回落到时段姿势 |

### 4.2 亲密度增长（带每日上限，防刷）

| 行为 | 增长 | 每日上限 |
|------|------|---------|
| 抚摸点击 | +2 | 10 次 |
| 阅读停留（每满 2 分钟） | +3 | 15 次 |
| 每日回访（当天首次打开站点） | +5 | 1 次 |

### 4.3 等级与称号

| 等级 | 称号 | 亲密度阈值 |
|------|------|-----------|
| 1 | 陌生 | 0 |
| 2 | 熟悉 | 50 |
| 3 | 好友 | 150 |
| 4 | 亲密 | 300 |
| 5 | 挚爱 | 600 |

面板展示当前称号与距离下一级的进度条。

### 4.4 说话气泡

- 页面停留期间每 3–6 分钟（随机）主动冒话：优先使用形象自定义 `quotes`；未配置时使用组件内置兜底短句池（今日一言为组件内联本地句池、无可调用的远程接口，为避免耦合不直接复用）
- 被抚摸时：显示反应短句 + 心心粒子动画

## 5. UI 与交互

- **左下角悬浮圆盘（FAB）**：显示当前姿势缩略图，hover 微光，点击打开面板；与右下角电台 FAB、返回顶部按钮形成三角平衡
- **面板**：卡片式浮层，沿用现有设计语言（圆角、`var(--primary)` 主题色、暗色模式自适应）
  - 宠物大图 + 名字 + 称号 + 亲密度进度条
  - 形象库网格：展示所有可收养形象，点击即收养/切换，选择立即持久化
  - 未收养状态：引导卡"小屋里还没有小伙伴，来收养一只吧"
- **移动端**：FAB 不遮挡正文，面板自适应屏宽
- **无障碍与偏好**：尊重 `prefers-reduced-motion`（关闭粒子动画）；FAB 与面板按钮具备 aria-label

## 6. 配置开关

`src/config.ts` 的 `funConfig` 新增：

```ts
pet: {
	enable: true,
	/** 未收养时展示 / 形象加载失败时回退的默认形象 id */
	defaultPet: "pikachu",
	panelTitle: "小屋宠物",
},
```

`enable: false` 时组件完全不渲染，不产生任何请求。

## 7. 起步素材

- 首个形象：**皮卡丘**（`id: pikachu`），三姿势（idle / sleep / happy），统一卡通画风，由 AI 图像工具生成
- 若生成工具对知名 IP 有限制，备选：生成"皮卡丘风格"的黄色电气鼠原创形象，或由用户自行提供图片
- 版权提示：皮卡丘为版权角色，个人博客自用无碍；若未来商业化建议替换为原创形象

## 8. 错误边界

| 场景 | 处理 |
|------|------|
| manifest 拉取失败 | 功能静默关闭，不影响主页面 |
| manifest 格式非法 | 跳过该功能，console.warn 提示 |
| 形象图片加载失败 | 回退 `defaultPet`，再失败显示 🐾 占位符 |
| localStorage 不可用 | 内存模式，刷新重置，不报错 |
| 未收养 / adopted 指向不存在的形象 | 展示引导卡或回退 `defaultPet` |

## 9. 测试与验收

- **单元测试**（`node --test`，`scripts/test/pet-logic.test.mjs`）：亲密度增长、每日上限、日期重置、等级阈值、姿势时段选择、姿势缺失回退
- **静态检查**：`pnpm check`、`biome check`、`pnpm build` 全部通过
- **手动验收**：
  - dev 预览各时段姿势表现
  - 抚摸涨亲密度、刷新后数据持久化
  - 收养 / 切换形象生效并持久化
  - 移动端布局不遮挡正文
  - `enable: false` 时完全隐藏
