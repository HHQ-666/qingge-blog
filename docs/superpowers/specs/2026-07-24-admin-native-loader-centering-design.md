# 写作台原生加载页居中设计

## 目标

让 Sveltia CMS 的原生 `Loading Site Data…` 加载页在桌面和移动端始终水平、垂直居中，同时不改变 CMS 后台就绪后的正常布局。

## 原因

当前居中扫描在遮罩首次被隐藏时停止，但 Sveltia 会在后续阶段替换为新的原生加载容器；该容器不再接受居中修正，因此内容回到偏左位置。

## 设计

- 扩大加载容器匹配范围，以覆盖 Sveltia 替换后的原生加载节点。
- 在原生加载页存在期间持续应用固定视口和 flex 居中样式。
- 仅在 CMS 真实后台界面就绪或加载失败时停止扫描与观察，避免影响后台的普通容器布局。
- Astro 路由与静态入口页保持同一实现。

## 验证

- 在宽桌面视口与移动视口中，原生 logo、标题和 Loading Site Data 文案位于页面正中央。
- CMS 就绪后，居中修正不再作用于后台内容区。
- 生产构建成功，两个入口页均包含相同的加载容器选择器。
