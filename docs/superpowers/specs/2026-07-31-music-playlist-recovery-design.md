# 音乐播放器 30 首在线曲库恢复设计

**日期：** 2026-07-31  
**状态：** 已确认，待实现

## 目标

恢复音乐播放器的多曲目体验，将当前运行时只显示一首歌的问题修复为稳定的在线曲库，并将精选歌单扩展到最多 30 首。

## 背景与边界

当前 `src/config.ts` 已经配置了多首歌曲，但播放器会在打开面板时逐首请求 Meting 音源。由于部分接口或音源失效，只有少数歌曲能进入 `loaded` 列表，页面因此看起来只剩一首“成都”。

本次使用现有 Meting 兼容接口和备用接口，不接入 GitHub 上直接分发未授权商业 MP3 的仓库。80/90 年代华语原唱的完整时长和音质只能以在线接口实际返回为准；不对接口没有提供的码率或版权信息做虚假承诺。

## 需求范围

- 默认歌单目标为 30 首，至少保留 20 首配置项。
- 每位歌手最多一首代表作。
- 优先选择 80 / 90 / 00 年代华语经典，也可以补充少量公认的 2000 年后经典歌曲。
- 优先使用原唱、正式录音室版本，排除 Live、翻唱、伴奏和明显试听片段。
- 歌单最多显示 30 首，不随接口结果无限增长。
- 保留顺序播放、随机播放、单曲循环、上一首、下一首和精简模式。
- 在线音源失败时，歌曲仍留在列表中并显示失败状态，不被静默删除。

## 设计

### 1. 曲库配置

`funConfig.musicPlayer.songs` 继续作为唯一的精选歌单来源。每项至少包含：

```ts
{
  id: string;
  title: string;
  artist: string;
}
```

配置维护 20–30 首歌曲，并在实现阶段增加静态校验，确保歌曲数量不超过 30、歌手不重复、歌曲名和歌手字段完整。接口返回的显示名称可以补充或校正配置，但不改变歌单顺序和歌手去重规则。

### 2. 音源适配与加载

播放器保留当前 `api` 和 `fallbackApis` 配置，将单首歌曲请求封装为统一的音源适配流程：

1. 读取歌曲元数据和本地缓存。
2. 先请求主 Meting 接口。
3. 主接口超时、限流、HTTP 错误或没有可用 URL 时，按顺序尝试备用接口。
4. 成功后将返回值归一化为播放器所需的 `id`、`name`、`artist`、`url`、`cover` 和可选的 `duration`。
5. 浏览器实际加载音频元数据，确认可以播放并检查时长。
6. URL 过期或播放错误时，只刷新当前歌曲的 URL，不影响其他歌曲。

请求具有单首超时、接口冷却和有限重试。并发数保持受控，避免打开播放器时瞬间请求所有接口。

### 3. 列表状态与展示

歌单列表由配置项驱动，而不是由成功请求结果驱动。每首歌曲有独立状态：

- `loading`：正在获取在线音源；
- `ready`：已获取音源并可播放；
- `failed`：接口或音频校验失败；
- `short`：返回内容明显短于 `minDurationSec`，视为试听片段。

面板顶部或提示区域显示总数和可播数，例如“共 30 首 · 当前可播放 18 首”。失败歌曲仍显示歌名和歌手，附带“音源暂不可用/非完整音源”提示，并允许点击重试。

自动播放遇到 `failed` 或 `short` 歌曲时跳过到下一首，但手动点击失败歌曲不会静默失败，而是触发一次重新请求并反馈状态。

### 4. 缓存

升级播放器缓存版本，缓存指纹至少包含：

- 歌曲 ID 顺序；
- 主接口和备用接口地址；
- 缓存版本。

只缓存成功获取的音源，不缓存失败状态作为永久结论。曲库、接口或校验规则变化时自动绕过旧缓存。URL 失效后重新请求并覆盖当前歌曲缓存。

### 5. 播放模式

沿用现有播放模式模块：

- 顺序播放：到末尾回到第一首；
- 随机播放：选择不同于当前曲目的歌曲；
- 单曲循环：保留当前歌曲。

模式设置继续写入本地存储，并统一作用于面板、精简播放器、媒体键和歌曲自然结束事件。

## 错误处理

- 单个接口失败：切换到下一个接口。
- 接口限流：记录短暂冷却时间，避免连续请求同一个失效接口。
- 单首歌曲失败：标记该项，不阻塞其他歌曲加载。
- 试听片段：标记为非完整音源，不当作完整歌曲展示。
- 音频 URL 过期：播放错误时刷新该歌曲 URL 并重试一次。
- 全部接口不可用：显示完整歌单元数据，并提示在线音源暂时不可用。
- 本地存储不可用或数据损坏：忽略缓存，重新加载，不影响播放器初始化。

## 验收标准

- 配置中有 20–30 首歌曲，歌手无重复，歌单不会超过 30 首。
- 打开播放器时能够看到配置中的完整歌单，而不是只看到请求成功的歌曲。
- 接口只成功返回一首时，页面仍显示全部歌曲，并准确显示“可播放 1 首”。
- 主接口失败时会尝试备用接口；单首失败不影响其他歌曲。
- 可播放歌曲可以切换、拖动进度并自然播放到下一首。
- 明显试听片段不会被标记为完整音源。
- 顺序、随机、单曲循环和精简模式行为保持正确。
- `pnpm astro check`、`pnpm test` 和生产构建通过。
- 在桌面和移动视口完成浏览器验证，确认 30 首列表滚动、状态提示、重试和播放器布局正常。

## 非目标

- 不下载、打包或镜像未授权商业歌曲。
- 不绕过音乐平台登录、DRM、地区限制或访问控制。
- 不替换现有播放器的视觉风格和主题系统。
- 不引入付费音乐平台账号体系。
- 不提供离线音乐下载功能。
