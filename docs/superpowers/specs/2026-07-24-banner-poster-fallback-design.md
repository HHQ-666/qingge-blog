# Banner 视频首帧兜底设计

## 目标

在首页刷新、通过搜索结果直接进入或视频加载失败时，Banner 必须立即显示与当前海浪视频一致的一帧静态画面；视频可播放后，仍按既有行为自动播放。该体验在桌面端与移动端一致。

## 范围

- 使用 `public/media/banner-ocean-poster.jpg` 作为唯一的 Banner 静态兜底资源。
- 将静态兜底层与原生 `<video>` 的 `poster` 属性指向同一资源。
- 保留延迟加载、静音循环播放、视频首次可用后淡入的行为。
- 删除 Banner 容器的默认浅紫色背景，避免静态图尚未绘制时出现与网站主题不一致的色块。

## 行为

1. HTML 初始渲染时先显示静态 poster，覆盖整个 Banner 区域。
2. 浏览器空闲时才为视频设置 `src` 并尝试静音播放。
3. 收到首帧可显示的事件后，视频以现有淡入动画覆盖 poster。
4. 如果视频加载超时、报错或自动播放被阻止，poster 保持可见，不显示空白状态。

## 兼容与错误处理

- 兜底图片由普通图片元素渲染，不依赖移动浏览器是否绘制 `<video poster>`。
- `poster` 仍保留在 `<video>` 上，作为静态层以外的第二层保护。
- 图片资源不可用时，Banner 使用站点主题相关的中性色，而不是固定浅紫色。

## 验证

- 桌面与移动视口下刷新首页：首屏先显示海浪静态帧，随后正常播放视频。
- 在开发者工具中阻止视频请求：静态帧保持显示，无空白或紫色色块。
- 检查生产构建，确保 Astro 类型检查与构建通过。
