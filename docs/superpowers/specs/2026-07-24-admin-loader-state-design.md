# 写作台加载遮罩状态设计

## 目标

让 Sveltia CMS 成功挂载后自动移除写作台加载遮罩；若 CMS 未能加载，则在 30 秒后提供清晰的失败提示和重试入口。

## 就绪判断

- 不再读取整个 `document.body` 的文本判断加载状态，因为遮罩自身包含“正在加载”文字。
- 仅检测 Sveltia 的 `.sui.app-shell` 内是否出现可交互控件或主内容区域。
- 检测到就绪后，隐藏并移除 `#admin-boot`。

## 失败状态

- 30 秒未检测到 CMS 就绪时，停止加载动画并将遮罩文案改为加载失败。
- 提供“重试”链接，以当前 `/admin/` 地址重新加载页面。
- 遮罩继续保留，避免在 CMS 未挂载时向用户展示空白页面。

## 一致性与验证

- `src/pages/admin/index.astro` 与 `public/admin/index.html` 使用相同的状态逻辑。
- 验证遮罩文字不会再参与就绪判断。
- 构建站点并检查生成的 `/admin/` 页面包含新的重试入口和 CMS 就绪选择器。
